# 写在前面：当“能跑”越来越便宜，“可维护”反而越来越贵。
- **别把“能跑”当“完成”**：Agent 能出画面、出原型只证明方向可能可行，不等同于**需求满足**、**结构可维护**、**异常可解释**。
- **长任务要先设计“能否定方案”的实验**：先用小 prototype 验证核心假设、细分依据依赖、硬限制和数据表达，避免 Agent 在错误的方向上无限补洞。
- **完成条件要写成可检查规格(Spec & SDD)**：任何功能都要明确 输入输出和数据形态、生命周期与不变量、依赖与时序假设、性能边界等。没写清的部分，等于把设计权默认交给模型。模型替你做的隐性决定，最终都会变成**维护成本**。


# AI 代码为什么会变成屎山？
1. **只打局部补丁，能跑就行**。AI倾向于在现有结构上叠加局部修复，而非重新审视模块边界并主动重构。你报“卡”它就加缓存 / 异步 / 防抖；你说“这里也要支持”，它就加 if / bridge / adapter；你说“旧逻辑不能坏”，它就写兼容层、兜底逻辑、双写逻辑；等等等等。
- 长期不**重画边界**，局部能过但**系统耦合**越来越重。而你和 reviewer 看到的只有“测试全绿，没有问题”。

2. **模块契约退化**。新增路径不遵守上游原有隐性保证（如数据形态/行为保证），接收方被迫各自增加防御性检查和兜底逻辑，导致各层之间互不信任、层层设防，在高频路径上所谓的“伪鲁棒”转化为沉重的性能债、破坏了系统模块/接口契约。AI slop 就来了。

3. **缺可抄的好范例**。当新领域没有同类好模块可参照时，AI实现能力强但设计空间没收住，坏惯例会被后续生成不断放大（即模式复制与架构漂移）。有时成熟的大仓库反而比空项目更容易改：代码量虽大，但大量设计决定已经做完了；空项目看起来干净，实际上每次局部实现都可能“顺手”决定了一个长期结构。而开头就形成了的坏惯例，后续生成又把坏惯例当成上下文，问题就会继续叠加，**架构就会持续漂移**。

# 软件工程：哪些决定必须人先做，哪些实现可以交给 AI 探索。
- **Code review 前，人必须能讲得清职责**：每个类/函数为何存在、谁拥有状态、接口保证什么、修改局部性如何，作者都`说不清`就不该进入大规模实现。
  - **架构选择不能被多Agent讨论替代**：多 Agent 调研、互审只是提速。如果共享了错误方向，只会越论证越偏。最终仍要有人能复述、能拍板、能负责。
  - **Mentor的价值是给“线索”**：资深人凭经验，通过现象直连历史bug、引擎硬限制、更新时序坑等，比让 Agent 盲搜能更快把**反馈前移**到设计与review。

- **人的核心能力转向问题与结构**：程序员不再只拼“写谁写不出”，而拼把模糊意图变成可检查规格、设计可演进结构、定位真问题、在看似正确实则漂移时正确叫停。
  - **AI 使用原则是“前置介入”**：边界清楚、可验收、可替换的活让 Agent 探索；跨模块接口、数据结构复杂、难回滚决定要提前 review。
  - **责任不能推给“AI写的”**：代码进项目、别人调用、出事要解释修复，负责人仍是人类。能回答“为什么存在、我讲得清楚、需求变了还能改”才算真做好了`软件工程`。

> e.g. 比如有一部分计算要改为异步，单独用一个类管理，只提供少量接口，接着明确每个接口能做什么，画出类之间的关系，再逐个检查私有成员、公开成员、私有方法和公开方法有没有多余，输入输出到底保证什么等等。
>   - 这一套东西不是关起门来写完然后再让AI执行。通常是我先描述边界，AI 调研现有实现并给出初稿，我们一起改，再叫老大讨论 review，最后定稿。当 AI 给出结论，我会追问依据、适用条件以及反例，AI 仍然负责大量调研与实现，但架构选择以及为什么，必须能被我复述讲清，禁得起 review。


# 小结一下
在一个真实 feature 里决定 **职责在哪里分割**，**状态由谁拥有**，**哪些保证由谁维护**，以及**怎样让下一次修改只发生在局部**，这都是我们应该考虑的事情。

**能不能从现象里找到真正的问题；能不能把模糊想法变成可检查的规格；能不能设计出允许持续修改的结构；能不能在结果只是看起来正确时发现它；能不能在问题还便宜的时候叫停**。


# 写在最后：心定
- 我觉得大部分人可以不必如此焦虑，AGI 的到来真的不会有那么快，更不会在一夜之间颠覆一切。规模化的边际收益正在急剧递减，纯堆算力的路已经越来越窄，数据、能耗、架构瓶颈接踵而至。
  - 现在遍地都在曲解AGI原本的定义与边界。不断稀释、不断降维，让 AGI 这个概念变成一个可以随意贴在任何产品上的标签。答案显而易见，这更多的是在不断**炒作**。

- **那些喊得最大声、喊得最急的，往往是最想从你口袋里掏钱的**。最让人感慨的，是那些还在读高中的孩子。他们的世界观尚未完全成形，对社会的判断力还在构建之中，却已经开始被铺天盖地的焦虑营销包围。甚至有的真相信了资本口中那套"弃学打工论"和"读书无用论"，每天刷着营销号，被贩卖焦虑。这些声音背后的逻辑链条极其简单：制造恐慌→兜售解药→收割韭菜。卖课是最典型的例子，但往往不只于卖课。
  - 要我说：**别让资本异化你的思想！**

- **解放思想，实事求是**！这八个字放在今天，依然是最锋利的武器。
  - 对小孩子不能指出(环境)问题，要给实践框架。不然只会变成神神和见证人。理论有高度，现实没角度。*应该教给孩子的是实践能力，而不是在他还没有能力保护自己的时候给他看社会比较难崩的一面*。你告诉他大学苦逼、社会更苦逼，屁用没有！那只会催生读书无用论，然后资本继续拱火，孩子们的思绪不再**实事求是**和**脚踏实地**……
  
> 点到为止，多的我只想说：“别让资本异化你的思想，多看看毛选吧。”
> 不是为了教条，而是为了学会用阶级分析的眼光去看那些裹着糖衣的叙事，去识别谁在说话、为谁说话、想让你做什么……

- 最后，**乐观**且**自信**一点。
